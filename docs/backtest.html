Composite score NBER recession 30 = YELLOW threshold 60 = RED threshold

How to read this: the model is calibrated for relative signal monitoring, not point-prediction. A useful model should spend most pre-recession periods in the YELLOW or RED zone before NBER calls a recession, and most expansion periods in GREEN. Crossings between zones during expansions are false positives; ideally there are few.

Limitations: the z-score window is 60 months (5 years), so very early backtest years have noisier scores. Layer weights are doctrinal, not optimized against NBER chronology, so this is a sanity check rather than a hold-out evaluation.
